# Snowflake Fitness Data Engineering Project

Fitness Calories Prediction using Machine Learning

This project predicts daily calories burned using fitness activity data collected over multiple months.

The dataset contains daily records such as:

Activity Date
Steps
Distance (KM)
Calories Burned
Day
Month
Year
